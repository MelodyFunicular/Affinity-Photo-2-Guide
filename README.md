## 📌 What is Affinity Photo 2?

Affinity Photo 2 is a **professional-grade photo editing application** offering layer-based editing, RAW development, and digital painting tools — designed as a one-time-purchase alternative to subscription-based editors.

## ✨ Key Features

| Feature                     | Description                                                  |
| ------------------------------ | ------------------------------------------------------------- |
| Non-destructive editing      | Layers, adjustment layers, live filters, and masks            |
| RAW development               | Built-in RAW engine, no separate app needed                   |
| Persona system                | Switch between Photo, Liquify, Develop, and Tone Mapping personas |
| Astrophotography stacking     | Built-in tools for stacking and blending night-sky shots      |
| Vector & pixel tools           | Combine raster editing with vector shapes in one document     |
| Cross-platform projects        | Open the same file seamlessly on desktop and iPad             |
| Focus merge & HDR merge        | Combine multiple exposures or focus points automatically      |
